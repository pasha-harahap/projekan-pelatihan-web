# projekan-pelatihan-web

# Zoo & Aquarium Edukasi

<p>Latihan membuat repositori di github yang berisikan : Projekan Ensiklopedia Digital Satwa menggunakan HTML, CSS, dan JavaScript.</p>

## Deskripsi Projekan

<p>Ini adalah website edukasi interaktif yang berisikan informasi mengenai berbagai macam satwa liar di darat (Zoo) dan hewan laut (Aquarium). Di sini kita bisa mencari nama hewan, melihat kategori, spesies, deskripsi lengkap, hingga fakta menarik beserta ilustrasi gambarnya.</p>

### 📄 Halaman dalam website ini :

<ul>
  <li> Beranda (Index)</li>
  <li> Zoo (Halaman Hewan Darat)</li>
  <li> Aquarium (Halaman Hewan Laut)</li>
  <li> Fitur Search / Pencarian Real-time</li>
  <li> Modal Detail Informasi Satwa (Pop-up Layar Penuh)</li>
  <li> Sistem Paginasi (Pagination Halaman)</li>
</ul>

## Keterangan Mengenai Yang ada di web tersebut

1. **Beranda**<br>
   Yaitu menampilkan halaman ZOO dan AQUARIUM
2. **Zoo**<br>
   Yaitu jika kita mengklik halaman Zoo maka kita akan bisa melihat data hewan darat
3. **Aquarium**<br>
   Sama seperti halaman Zoo namun ini akan menampilkan data hewan laut
4. **Fitur Search / Pencarian**<br>
   Yaitu fitur yang dapat mencari nama hewan dan fitur ini berada di Halaman Zoo dan Halaman Aquarium
5. **Modal Detail Informasi Satwa**<br>
   Yaitu saat kita klik salah satu hewan maka akan menampilkan data atau deskripsi dari hewan tersebut
6. **Sistem Paginasi**<br>
   Yaitu sistem yang berfungsi saat kita ingin melihat hewan selanjutnya atau sebelumnya dan sistem ini berada di halaman Zoo dan Aquarium
7. **Footer (Tentang Website Ini)**<br>
   Yaitu bagian paling bawah website yang berisi informasi bahwa Pusat Informasi Edukasi Satwa adalah ensiklopedia digital interaktif satwa liar, serta mencantumkan keterangan hak cipta tahun 2026 untuk tujuan pembelajaran.

## Cara Menjalankan Proyek

1. Clone repositori ini:`git clone https://github.com/pasha-harahap/projekan-pelatihan-web.git`
2. Buka folder proyek menggunakan **Visual Studio Code**.
3. Jalankan file `index.html` menggunakan browser atau ekstensi **Live Server** di VS Code agar *Fetch API* data JSON lokal dapat berjalan dengan sempurna.
