# projekan-pelatihan-web

# 🦁 Zoo & Aquarium Edukasi

<p>Latihan membuat repositori di github yang berisikan : Projekan Ensiklopedia Digital Satwa menggunakan HTML, CSS, dan JavaScript.</p>

## 📂 Deskripsi Projekan

<p>Ini adalah website edukasi interaktif yang berisikan informasi mengenai berbagai macam satwa liar di darat (Zoo) dan hewan laut (Aquarium). Di sini kita bisa mencari nama hewan, melihat kategori, spesies, deskripsi lengkap, hingga fakta menarik beserta ilustrasi gambarnya.</p>

### 📄 Halaman dalam website ini :

<ul>
  <li>🏠 Beranda (Index)</li>
  <li>🦁 Zoo (Halaman Hewan Darat)</li>
  <li>🌊 Aquarium (Halaman Hewan Laut)</li>
  <li>🔍 Fitur Search / Pencarian Real-time</li>
  <li>📖 Modal Detail Informasi Satwa (Pop-up Layar Penuh)</li>
  <li>📑 Sistem Paginasi (Pagination Halaman)</li>
</ul>

## 🚀 Cara Menjalankan Proyek

1. 1. Clone repositori ini: `git clone https://github.com/pasha-harahap/projekan-pelatihan-web.git`
2. Buka folder proyek menggunakan **Visual Studio Code**.
3. Jalankan file `index.html` menggunakan browser atau ekstensi **Live Server** di VS Code agar *Fetch API* data JSON lokal dapat berjalan dengan sempurna.
